You can create node by using the following syntax of cypher 
Cypher : Graph query language for neo4j 

"Create" command is used tyo create nodes and relationshsips between nodes 
"RETURN" command is used to display the node on screen 

lets create 2 nodes of a social network, i.e 2 persons 

1st lets see the structure of create statement 

CREATE (veriableName:NodeType {attribute1: value1, attribute2: value2, .....} ), (other node in same pattern), (), ....

RETURN veriableName

now lets see it with actual data 

VeriableName: can be any name of veriable, this is actually an object/ pointer that holder reference of the node created in memory, like n1, node1, person etc (in lowerCamelCase recommended)

NodeType : can be Any Name of Nodes TYPE or CLASS, i.e many nodes can belong to same class or Type, let say Person, Student , Teacher (UpperCamelCase Recommended)  

then comes dictionary containing all the attribtes and values pairs coma seperted, 
can be anything, lowercase recommended 

Commands like CREATE, RETURN, MERGE, MATCH etc ALL_CAPS_ON recommended 

"""

CREATE (n1 : Person {name:"ali", age:25}), (n2: Person {name:"alia", age:2})
RETURN n1, n2
